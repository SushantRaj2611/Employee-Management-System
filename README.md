# Employee Management System

A simple and responsive Employee Management System built using HTML, CSS, Bootstrap 5 and JavaScript.

## Features

- Add new employees
- Edit employee details
- Delete employees
- Search employees
- Filter employees by status
- Sort employees alphabetically (A-Z and Z-A)
- Dashboard with total, active and inactive employee counts
- Store employee data using LocalStorage
- Responsive user interface using Bootstrap 5

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript (ES6)
- LocalStorage

## How to Run

1. Clone this repository:

```bash
git clone https://github.com/SushantRaj2611/Employee-Management-System.git
```

2. Open the project folder in VS Code.

3. Install the Live Server extension.

4. Right-click on `index.html`.

5. Select **Open with Live Server**.

## Data Storage

This project uses browser LocalStorage to save employee information. Data remains saved after refreshing the page in the same browser.
